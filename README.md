# AegisAppSec Suite 🛡️

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Build Status](https://img.shields.io/badge/build-passing-brightgreen.svg)](#)

A lightweight, browser-based security suite built with AI collaboration. **AegisAppSec Suite** brings client-side static security analysis and secure cryptographic vault management directly into your browser—with zero backend dependencies or complex server setups required.

---

## 📦 What's Included?

* 🔍 **AegisPulse SAST** — A client-side static application security testing engine that maps web security findings to **OWASP Top 10** and mobile security checks to **OWASP MASVS**.
* 🔐 **ByteVault** — A browser-based cryptographic vault and digital notary tool for secure, client-side data handling and storage.
